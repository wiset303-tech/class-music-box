# 우리 반 오르골

원형 유리 돔 안에서 사진이 돌아가고, 오르골 소리로 파헬벨 캐논 등이 흐르는 3D 오르골입니다.
빌드 없이 `index.html`만 열어도 동작하며, GitHub Pages로 링크 하나로 배포할 수 있어요.

## 사용법
- **돔 열기**: 오르골을 누르면 유리 돔이 열리고 사진이 커집니다. 닫기는 `✕ 닫기`, Esc, 바깥 클릭.
- **확대·축소**: 화면 오른쪽의 막대를 끌거나 ＋/－ 를 누르세요(전자칠판 터치용). 마우스 휠·두 손가락 핀치도 됩니다.
- **사진**: 사진에 마우스를 올리면 메뉴(🔍 크게 보기 / 📷 바꾸기 / ✂️ 편집 / 🗑 빼기)가 나옵니다. 파일을 화면에 끌어다 놓아도 됩니다. 터치 화면은 사진을 탭하세요.
- **글자**: `✏️ 글자 바꾸기`에서 맨 위 제목, 오르골 명판, 사진 아래 이름을 바꿉니다.
- **시안**: 클래식 원목 / 스위트 파스텔 / 별밤 블루 탭.
- **음악**: 곡 선택(파헬벨 캐논, 환희의 송가, 반짝반짝 작은 별, 엘리제를 위하여, 생일 축하) 또는 `🎧 내 음악`으로 내 파일 넣기.

## 개인정보
사진과 글자는 **사용하는 브라우저 안에만** 저장됩니다(localStorage, IndexedDB). 서버로 전송되지 않고, 이 저장소에도 올라가지 않습니다.
학생 사진 파일은 저장소에 커밋하지 마세요(`.gitignore`로 막아 두었습니다).

## 저작권
내장곡은 모두 저작권이 만료된 곡이며, 악보를 코드로 옮겨 Web Audio로 합성합니다(음원 파일 없음).
`내 음악`으로 넣은 파일은 그 브라우저에만 저장되며, 저작권이 있는 곡은 교실 안에서만 사용하세요.

## 배포 (GitHub Pages)
저장소 Settings → Pages → Build and deployment → Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 지정합니다.
(비공개 저장소의 Pages는 GitHub 유료 플랜이 필요합니다.)

## 구성
- `index.html`, `app.js` — 화면과 로직
- `lib/three.min.js` — three.js r128 (CDN 없이 동작)
- `CODEX_PROMPT.md` — 앨범 확장(사계절·열두 달·우리 반)을 Codex에 맡기기 위한 작업 프롬프트
